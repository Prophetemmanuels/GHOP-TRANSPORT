## 🚀 Quick Start Guide (Local Development)

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (version 18+ or 20+ recommended) installed.

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/your-username/ghop-zambia-luxury-studios.git

# Navigate into the project folder
cd ghop-zambia-luxury-studios

# Install dependencies
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to explore the live application.

### 4. Build for Production
```bash
npm run build
```
The optimized, single-file production build will be generated in the `dist/` directory.

### 5. Preview Production Build
```bash
npm run preview
```

## 📦 Pushing to GitHub & Deployment

### Step 1: Initialize Git Repository (if not already done)
```bash
git init
git add .
git commit -m "feat: initial commit of GHOP Zambia Luxury Studios & Academy platform"
```

### Step 2: Push to GitHub
```bash
# Create a new repository on GitHub (e.g. ghop-zambia-luxury-studios)
git branch -M main
git remote add origin https://github.com/<your-github-username>/ghop-zambia-luxury-studios.git
git push -u origin main
```

### Step 3: Deploy to GitHub Pages (Automated via GitHub Actions)
A preconfigured workflow is included in `.github/workflows/deploy.yml`. 
1. Go to your GitHub repository **Settings** > **Pages**.
2. Under **Build and deployment**, set the Source to **GitHub Actions**.
3. Every push to the `main` branch will automatically build and publish your site!

### Step 4: Deploy to Vercel or Netlify (1-Click)
- **Vercel:** Import your GitHub repo at [vercel.com/new](https://vercel.com/new). Framework Preset: `Vite`. Build Command: `npm run build`. Output Directory: `dist`.
- **Netlify:** Import your GitHub repo at [app.netlify.com](https://app.netlify.com/). Build Command: `npm run build`. Publish Directory: `dist`.
